## 📄 2. شرح مفصل لكل ملف على حدة (File-by-File Breakdown)

### أولاً: ملفات جذر المشروع (Root Files)

1. **`package.json`**:
   - يحتوي على معلومات المشروع (`name: youssef-app`)، إصدارات التبعيات مثل `next ^15.1.0`، `react ^19.0.0`، `firebase ^11.1.0`، `framer-motion`، و `lucide-react`.
   - يحدد أوامر التشغيل: `npm run dev` (التطوير المحلي)، `npm run build` (البناء الثابت)، و `npm run save` (الحفظ على GitHub).
2. **`next.config.ts`**:
   - يحدد إعدادات Next.js؛ أهمها تفعيل التصدير الثابت `output: 'export'` لإنتاج مجلد `out/` جاهز للنشر على أي استضافة بدون سيرفر Node.js.
3. **`tsconfig.json`**:
   - تكوينات مترجم TypeScript، وتعيين مسار الاختصار `@/*` ليشير مباشرة لمجلد `./src/*`.
4. **`.env.local`**:
   - يحتوي على المفاتيح السرية الخاصة بمشروع Firebase (`NEXT_PUBLIC_FIREBASE_API_KEY`, `PROJECT_ID`, `DATABASE_URL`...).
5. **`firestore.rules`**:
   - قواعد الأمان المشددة لقاعدة بيانات Firestore؛ تضمن أن المستخدم لا يمكنه قراءة أو تعديل إلا المحادثات والرسائل الخاصة به فقط، مع تأمين توكنات FCM تحت `users/{userId}/fcmTokens`.
6. **`database.rules.json`**:
   - قواعد أمان Realtime Database لمتابعة حالة التواجد (`presence`) والكتابة الحية (`typing`).
7. **`wrangler.jsonc`**:
   - ملف تكوين استضافة Cloudflare Pages؛ يحدد اسم المشروع ومجلد الخرج الثابت `./out` مع `"not_found_handling": "single-page-application"`.
8. **`install.bat` / `run_dev.bat` / `save_to_github.bat`**:
   - أدوات تشغيل سريعة لمطور النظام لتثبيت الحزم، تشغيل الخادم المحلي، وحفظ الكود بنقرة واحدة عبر البوت.

1. **`scripts/sync-github.js`**:
   - سكربت فوري يقوم بفحص التعديلات، إضافتها (`git add .`)، عمل Commit برسالة محددة، ثم رفعها إلى المستودع الرسمي على GitHub.
2. **`scripts/github-bot.js`**:
   - بوت ذكي يقوم بفحص حالة المستودع، التحقق من بيانات المصادقة بأمان من `git-auth.json`، وتأكيد التغييرات والرفع التلقائي لـ GitHub.
3. **`scripts/build-report-10.js`**:
   - أداة أتمتة مخصصة تقوم بقراءة أحدث الأكواد الحية من كافة ملفات منظومة الإشعارات وحقنها وتوليد التقرير العاشر `10_NOTIFICATIONS_CALLS_MOBILE_FIXES.md`.

### ثالثاً: مجلد الدوال السحابية (`functions/`)

1. **`functions/src/index.ts`**:
   - دوال Firebase Cloud Functions (v2 Firestore triggers):
     - `onNewMessage`: ترسل إشعار دفع سحابي (Push Notification) فوري لجميع أطراف المحادثة عند إنشاء رسالة جديدة، مع احترام تفضيلات المستخدم وقائمة الحظر وتجهيل النص المشفر.
     - `onIncomingCall`: ترسل إشعار رنين عالي الأولوية بمجرد بدء مكالمة جديدة (`calls/{callId}`) لتنبيه الطرف المستلم حتى لو كان الهاتف مقفلاً تماماً.
2. **`functions/package.json`**:
   - يحدد بيئة Node.js 18 وتبعيات `firebase-functions ^6.0.0` و `firebase-admin ^13.0.0`.
3. **`functions/tsconfig.json`**:
   - إعدادات بناء مترجم TypeScript لكود الباك إند السحابي.

### سادساً: مجلد الخدمات والمنطق (`src/lib/`)

1. **`src/lib/notifications.ts`**:
   - المحرك المركزي لإدارة Firebase Cloud Messaging في الواجهة الأمامية:
     - `enableNotifications(uid)`: طلب إذن المتصفح وتسجيل توكن FCM في Firestore.
     - `refreshToken(uid)`: التحديث الصامت للتوكنات عند دورانها (Token Rotation).
     - `disableNotifications(uid)`: حذف التوكن عند تسجيل الخروج لمنع اختراق الخصوصية.
     - `listenForeground()`: الاستماع وتمرير الإشعارات في الواجهة أثناء فتح التطبيق.
     - `listenNotificationClicks()`: توجيه نافذة المتصفح فوراً لـ `/chat/${chatId}` أو صفحة المكالمات `/calls`.
2. **`src/lib/contexts/AuthContext.tsx`**:
   - يوفر بيانات المستخدم الحالي، حالة تسجيل الدخول، والتحقق الدوري من البروفايل.
3. **`src/lib/contexts/ChatContext.tsx`**:
   - يدير قائمة محادثات المستخدم المستمعة من Firestore، والمحادثة النشطة حالياً (`activeChat`).
4. **`src/lib/contexts/CallContext.tsx`**:
   - يدير حالة المكالمات الواردة والصادرة، الاستماع لمستندات الاتصال، وتشغيل الصوتيات.
5. **`src/lib/firebase/firestore.ts`**:
