# 🛠️ جدول التقنيات والمكتبات المستخدمة (Tech Stack & Dependencies)

يستخدم مشروع **Youssef App** أحدث حزمة تقنية (Modern Fullstack Web Technologies) تركز على الأداء الفائق، الخفة، والتوافق العالي مع متصفحات الهواتف والكمبيوتر.

---

## 1. التقنيات الأساسية (Core Technologies)

| التقنية | الإصدار | دورها في المشروع |
| :--- | :--- | :--- |
| **Next.js** | `^15.1.0` (App Router) | إطار العمل الرئيسي للواجهة، يدعم بناء صفحات React بأعلى سرعة وأقل حجم كود مع ميزة التصدير الثابت (`output: 'export'`). |
| **React** | `^19.0.0` | مكتبة بناء واجهات المستخدم التفاعلية، وإدارة المكونات وحالات الواجهة (State Management). |
| **React DOM** | `^19.0.0` | التعامل المباشر مع شجرة عناصر المتصفح وتصيير المكونات بأداء متقدم. |
| **TypeScript** | `^5.7.0` | لغة البرمجة الرئيسية لكتابة كود آمن من الأخطاء مع تعريف الأنواع والبيانات بدقة (`Types & Interfaces`). |
| **Google Firebase SDK** | `^11.1.0` | البنية التحتية السحابية لإدارة المستخدمين وقواعد البيانات اللحظية. |
| **WebRTC API** | متوافق مع كافة المتصفحات الحديثة | بروتوكول الاتصال المباشر من جهاز لجهاز (Peer-to-Peer) للمكالمات الصوتية والمرئية الحية بدون خوادم وسيطة ثقيلة. |

---

## 2. حزم ومكتبات الواجهة والرسوميات (UI & Animation Libraries)

| الحزمة | الإصدار | الوظيفة |
| :--- | :--- | :--- |
| **Framer Motion** | `^11.15.0` | تحريك المكونات، القوائم المنسدلة، والنوافذ المنبثقة بحركات فيزيائية ناعمة وسريعة. |
| **Lucide React** | `^0.468.0` | حزمة أيقونات SVG نظيفة وعصرية تستخدم في نوافذ الاتصال، المرفقات، والملف الشخصي. |
| **Google Material Symbols Outlined** | CDN (Web Font) | الأيقونات الرسمية لمطابقة أسلوب وتصميم تطبيق WhatsApp الأصلي في الهيدر، الفلاتر، وقوائم الشات. |
| **Inter Google Font** | CDN (300 إلى 800) | الخط العصري المعتمد في التطبيق لقراءة مريحة وواضحة لجميع اللغات (الإنجليزية والأرقام). |

---

## 3. خدمات وتكوينات Firebase السحابية (Firebase Modules)

| الخدمة | الغرض الفني |
| :--- | :--- |
| **Firebase Authentication** | تسجيل دخول المستخدمين بأسماء مستخدمين وكلمات مرور مشفرة، وإدارة الجلسات اللحظية. |
| **Cloud Firestore** | قاعدة البيانات المستندية الموزعة لتخزين بيانات المستخدمين، المحادثات، الرسائل، وقنوات إشارات المكالمات (`Signaling Channel`). |
| **Firebase Realtime Database** | قاعدة بيانات لحظية فائقة الخفة لمتابعة حالة التواجد المباشر (`Online / Offline Presence`) ومؤشرات الكتابة (`Typing Indicators`). |
| **Firebase Cloud Storage** | مرفوعة كإعداد احتياطي لتخزين الوسائط مع دعم التشفير الداخلي المباشر للصور بتقنية Base64 لتوفير أقصى سرعة عرض فوري. |

## 4. نظام التنسيق والتصميم (Styling System)

- **Vanilla CSS Modules**:
  - تم الاعتماد على CSS Modules (`chat.module.css`, `auth.module.css`, `calls.module.css`) لضمان عزل كامل للتنسيقات ومنع تضارب الكلاسات البرمجية.
- **CSS Custom Properties (Design Tokens)**:
  - كافة الألوان والمسافات والظلال محددة كرموز تصميم موحدة في `src/app/globals.css`:
    - `--surface-container-lowest`: `#0e0e0e` (خلفية الشات الداكنة).
    - `--surface-container-low`: `#1c1b1b` (خلفية الشريط الجانبي والقوائم).
    - `--surface-container-high`: `#2a2a2a` (خلفية حقول البحث والأفاتار).
    - `--primary`: `#59dcb5` (اللون الأخضر الزمردي المميز).
    - `--primary-container`: `#00a884` (لون أزرار الإجراءات والشارات).
    - `--on-surface`: `#e5e2e1` (لون النصوص الأساسية).

## 5. بيئة البناء والتطوير والتشغيل (DevOps & Build Tools)

| الأداة | الاستخدام |
| :--- | :--- |
| **Next.js CLI** | أوامر التطوير (`npm run dev`) والبناء للإنتاج (`npm run build`). |
| **Wrangler / Cloudflare Pages** | إعدادات استضافة النسخة الثابتة على شبكة حافة Cloudflare فائقة السرعة (`wrangler.jsonc`). |
| **Node.js Scripts** | سكربتات المزامنة التلقائية والرفع الآمن على مستودع GitHub (`scripts/sync-github.js` و `scripts/github-bot.js`). |
| **Windows Batch Scripts** | ملفات تشغيل سريعة بنقرة واحدة للمطور (`install.bat`, `run_dev.bat`, `save_to_github.bat`). |
