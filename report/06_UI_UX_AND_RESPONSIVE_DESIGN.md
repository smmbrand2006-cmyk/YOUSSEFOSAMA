## 2. وضع سطح المكتب والمحاكي (Desktop & Emulator Workstation)

عندما يكون عرض الشاشة أكبر من 768 بكسل، يدخل التطبيق وضع المحطة الشاملة (Workstation View):

1. **شريط الأيقونات الأيسر (Icon Rail - بعرض 70px)**:
   - مأخوذ من تصميم WhatsApp Web الأصلي لسطح المكتب.
   - يضم أيقونات التنقل السريع: المحادثات (`chat`)، المكالمات (`call`)، الحالات (`motion_photos_on`)، القنوات (`groups`)، مع صورة بروفايل المستخدم في الأسفل.
2. **الهيدر العلوي لسطح المكتب (AppHeader - بارتفاع 56px)**:
   - يعرض علامة "Workstation" مع نقطة خضراء متوهجة وكود المستخدم الحالي (مثال: `#123456`).
   - يضم أزرار البحث السريع، كتم أو تفعيل أصوات الإشعارات، والبروفايل.
3. **تقسيم الشاشة بنسبة 46% (Split-Pane Sidebar)**:
   - عرض ثابت ومدروس لقائمة المحادثات يمنح سهولة في تصفح الأسماء والرسائل الأخيرة دون إخفاء شاشة الشات المفتوحة.
4. **شاشة نقطة الصفر الترحيبية (Point Zero Canvas)**:
   - عند عدم فتح شات، تظهر مساحة فارغة أنيقة مزينة بـ **SVG Tile** لنقوش واتساب الداكنة الأصلية بشفافية 3% وشعار التطبيق.

## 3. وضع الموبايل الذكي (WhatsApp Mobile Dark Design)

عندما يكون عرض الشاشة 768 بكسل أو أقل (الهواتف الذكية):

```text
+-------------------------------------------------------+
|  [💬] Chats                      [🔍] [📷] [⋮] [(👤)] | <- Tier 1 (h-14)
|  [🔍 Search conversations...                        ] | <- Tier 2 (h-11)
|  (All)  (Unread)  (Favourites)  (Groups)  (+)         | <- Tier 3 (Pills)
+-------------------------------------------------------+
|  [📁] الدعم الفني والمؤرشفة (#123)            [24/7] | <- صف الأرشيف
|-------------------------------------------------------|
|  (👤 52px)  اسم المستخدم          10:30 ص            |
|             نص الرسالة الأخيرة...      [✓✓ أخضر]      |
|-------------------------------------------------------|
|  (👤 52px)  محادثة أخرى           أمس                |
|             رسالة واردة جديدة          (1) أخضر       |
|                                                       |
|                                         [ 💬 FAB ]    | <- زر عائم
+-------------------------------------------------------+
|   [💬]        [📞]         [👥]        [⭕]      [⚙️]  | <- BottomNav (h-16)
|   Chats      Calls      Communities   Status   Settings
+-------------------------------------------------------+
```

### تفاصيل مكونات الموبايل:
1. **الهيدر ثلاثي الطبقات (3-Tier Header - بارتفاع h-44)**:
   - **الطبقة 1**: شارة شات دائرية + عنوان Chats + أزرار البحث، فتح كاميرا الهاتف مباشرة، القائمة المنسدلة، وأيقونة البروفايل.
   - **الطبقة 2**: شريط بحث مخصص بكبسولة منحنية لكتابة الاسم أو الكود.
   - **الطبقة 3**: شريط كبسولات التصفية الأفقية (All, Unread, Favourites, Groups, +).
2. **صف الدعم الفني والمؤرشفة**:
   - صف مثبت بتصميم أيقونة الأرشيف للوصول الفوري لخدمة العملاء (#123) بضغطة واحدة.
3. **صفوف المحادثات بقطر 52 بكسل**:
   - صور رمزية للمستخدمين بقطر 52px مع نقطة الاتصال الخضراء وعلامات القراءة المزدوجة الخضراء (`done_all`).
4. **الزر العائم (FAB - Floating Action Button)**:
   - زر أخضر دائري بقطر 56px مثبت في أسفل يمين الشاشة لبدء محادثة جديدة فوراً.
5. **شريط التنقل السفلي الثابت ([`MobileBottomNav.tsx`](file:///c:/Users/youse/OneDrive/Desktop/youssef%20app/src/components/chat/MobileBottomNav.tsx))**:
   - بارتفاع 64px مع تأثير زجاجي (`backdrop-blur-xl`) يضم الأقسام الخمسة: Chats, Calls, Communities, Status, Settings.
6. **الانتقال لملء الشاشة أثناء المحادثة**:
   - فور النقر على أي محادثة، يختفي شريط التنقل السفلي والقائمة الجانبية، ويتحول الشات إلى وضع ملء الشاشة مع زر رجوع علوي للعودة السلسة.

## 4. المكونات التفاعلية وتجربة التطبيق الأصلي (Native Feel & Micro-interactions)

1. **حماية اللمس وتجربة التطبيق الأصلي (Anti-Touch-to-Search)**:
   - إلغاء تحديد النصوص غير المرغوب فيه عبر `user-select: none !important` و `-webkit-touch-callout: none !important`.
   - إلغاء وميض اللمس الرمادي (`-webkit-tap-highlight-color: transparent`).
   - حصر إمكانية تحديد النصوص فقط داخل حقول الإدخال والـ textarea.
2. **شريط تسجيل الفويس التفاعلي (Voice Note Recording Bar)**:
   - نقطة حمراء نابضة مستمرة 🔴 مع عداد زمني للثواني والدقائق.
   - زر إرسال مباشر للأوديو وزر سلة محذوفات لإلغاء التسجيل فوراً.
3. **مشغل الفويس داخل المحادثة (`VoiceNotePlayer`)**:
   - زر تشغيل/إيقاف أنيق، شريط تقدم زمني متدرج، ومؤشر وقت متبقي للرسالة الصوتية.
4. **عارض الصور بملء الشاشة (Fullscreen Media Lightbox)**:
   - خلفية مظلمة بنسبة 95% مع زر إغلاق وزر تحميل سريع للصورة بجودتها الكاملة.
5. **شاشة عرض مشاهدي الاستوري (Stories Viewers Bottom Sheet)**:
   - شريط مشاهدات شفاف في أسفل الحالة، ينبثق عند لمسه ليعرض قائمة بجميع من شاهدوا الاستوري مع أوقات المشاهدة باللغة العربية.
6. **نافذة الأذونات الشاملة وتثبيت PWA (`MandatoryNotificationModal`)**:
   - واجهة عصرية متدرجة تطلب الصلاحيات الحيوية (إشعارات + ميكروفون + كاميرا) بخطوات سلسة ومفتاح تجربة إشعار فوري.
